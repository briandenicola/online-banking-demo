# Orchestration Log: Turk — Local Docker-Compose API Gateway Fix
**Date:** 2026-06-05 | **Agent:** Turk | **Mode:** Sync | **Requester:** Brian

## Summary
Fixed local docker-compose /api gateway routing for React UI. Root cause: host DNS search domain `denicolafamily.com` with ndots:0 leaked into compose container name resolution, causing nginx resolver to append it to service names and send upstream lookups to external wildcard hosts, resulting in login 405→502/404 errors.

## Solution
1. **Reverted image-baked config:** `src/ui-app/nginx.conf` restored to HEAD (AKS-safe, no local gateway references)
2. **Local-only override:** Created `infrastructure/local/ui-app.nginx.conf` mounted via docker-compose at `/etc/nginx/nginx.conf` for ui-app service only
3. **DNS leak fix:** Added `dns_search: ["."]` to both `gateway` and `ui-app` services to prevent host domain leakage
4. **Gateway routes:** `infrastructure/local/gateway.nginx.conf` maintains path maps for `/api/*` routing to backend containers

## Files Modified
- `docker-compose.yml` — added dns_search, ui-app nginx mount, gateway service configuration
- `infrastructure/local/gateway.nginx.conf` — created with upstream routing rules
- `infrastructure/local/ui-app.nginx.conf` — created with same-origin proxy rules
- `.squad/skills/docker-compose-dns-search-leak/` — documented DNS search domain issue
