## Resolution

1. **UserService (Cosmos DB):** Added `IsContainerEmptyAsync()` method to check if user container is empty before creating new user. If empty, new user gets `Role = "admin"`.

2. **InMemoryUserService:** Added parallel check on the in-memory user dictionary. If empty, first user promoted to admin.

3. **Audit logging:** Both services log the promotion at INFO level for auditability.
