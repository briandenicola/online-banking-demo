## Key Design Decisions

1. **State Machine:** Validated transitions with audit logging; admin review can override early statuses
2. **Event Publishing:** Redis Streams for async agent communication
3. **Consumer Pattern:** Base class for agent workers to subscribe and process events
4. **Authentication:** JWT token validation via Azure Entra ID
5. **Backward Compatibility:** Accepts both flat and structured form fields during Phase 1
6. **Separate Deployment:** API server and worker containers are independent
