## Summary

Linus delivered frontend design spike establishing three-pane work surface (task queue / live plan-trace / artifact canvas) with command input demoted to bottom bar. Admin tabs phased: flagged transactions/applications subsumed as task sources; classic read-only retained through Phase 2; user management explicitly L3. Transport: SSE over `fetch` + `ReadableStream` with bearer auth (not `EventSource`, not WebSocket). **Critical finding: `proxy_buffering off` absent from nginx configs (infra/local/gateway.nginx.conf and ui-app.nginx.conf) — without it, entire trace arrives as one lump, defeating live-harness illusion. Highest-risk non-frontend dependency, needs owner now.** State uses external store + `useSyncExternalStore`. Approval UX invariants: "Sign — <action>" labels, "expires in MM:SS → DENIED" copy, evidence deep-links. L2 disagreement flagship screen with side-by-side opinions. Signature void handling with field-level diff display. Anti-fatigue mechanisms: stakes-scaled dwell timers, `IntersectionObserver` gate, batch approval capped at 10 items, spot checks, per-session meter, visual variance bounds. Accessibility: live region split from visual region; `aria-live="off"` for trace, coalesced 2500ms summaries. Sequencing: build against flagged transactions first, loans showcase once #140 lands.
