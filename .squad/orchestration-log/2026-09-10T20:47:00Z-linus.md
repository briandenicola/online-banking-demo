# Linus — API path fixes, pane layout, approval detail centre, stream stability

## Work Delivered

### 1. Doubled API Prefix Fix (Fixed)
- **Issue:** Client API calls were prefixed twice: `/api/api/...` instead of `/api/...`
- **Root Cause:** `api/client.ts` `apiPath()` helper was adding `/api/` but caller sites (`api/copilot.ts`, `api/approvals.ts`) were prepending `/api/` again
- **Fix:** Introduced single `apiPath()` source of truth; verified across all call sites
- **Files:** `src/ui-app/src/api/client.ts`, `src/ui-app/src/api/copilot.ts`, `src/ui-app/src/api/approvals.ts`
- **Impact:** Task queue now renders (was 404 before)

### 2. HTTP Failure Descriptions (New)
- **Feature:** New `api/errors.ts` module with `describeHttpFailure()` for human-readable error messaging
- **Files:** `src/ui-app/src/api/errors.ts`

### 3. Copilot Pane Layout (Fixed)
- **Issue 1:** Command bar clipped to 24px due to `flex-shrink: 1` on `flexbox` container
- **Fix:** Set `flexShrink: 0`
- **Issue 2:** ~950px blank scroll below 100vh shell due to `ApprovalCountdown` `position: absolute` with no positioned container
- **Fix:** Set shell `position: relative`
- **Issue 3:** Footer suppressed on `/copilot`; queue column width now breakpoint-based (`md 240 / lg 280 / xl 300`); layout now keys on viewport height (`max-height: 820px`)
- **Files:** `src/ui-app/src/components/AppShell.tsx`, `src/ui-app/src/components/copilot/*`
- **Layout Regression:** All four panes lacked `flexGrow`, so pane width was content-based. `TracePane` collapsed to 426px in 750px region. Fixed on all panes.
- **Test:** Regression verified; `Expected <= 2, Received 324` before fix

### 4. Centre Pane Architecture — Approval Detail (Implemented, per Danny's ruling)
- **Rule:** `runActive = Boolean(run)`. Run owns centre pane when active; otherwise centre shows selected approval
- **Transition:** Run starts → approval moves to right-dock labelled "Selected approval"; run finishes → trace stays (not reverted)
- **Component:** `ApprovalDetailPane` wraps `ApprovalCard` unchanged; signing gate untouched
- **Viewport Testing:** Verified on 5 viewports; all signing gates functional
- **Files:** `src/ui-app/src/components/copilot/ApprovalDetailPane.tsx` (new), `src/ui-app/src/components/copilot/CopilotHarness.tsx`

### 5. SSE Stream — Terminal Frame + Reconnect Storm (Fixed)
- **Issue:** Client reconnect-storm on stream close; terminal frame was ignored
- **Root Cause:** Stream close logic did not check whether a frame was terminal before attempting reconnect
- **Fix:** New terminal frame handling in `CopilotContext.tsx`; frame with `terminal: true` sets `streamStatus: 'terminal'` and disables reconnect
- **Files:** `src/ui-app/src/components/copilot/CopilotContext.tsx`
- **Test:** New `signingGateColdLoad.test.tsx` validates gate state on cold start

### 6. Evidence Findings Plumbing (Fixed)
- **Issue:** Evidence `findings` field value was lost client-side during wire mapping
- **Fix:** Preserved `EvidenceRef.findings` field in `api/authorityWire.ts` `toEvidence()` function
- **Display:** Evidence findings now correctly render in `ApprovalCard.tsx` `EvidenceList`
- **Files:** `src/ui-app/src/api/authorityWire.ts`, `src/ui-app/src/components/copilot/ApprovalCard.tsx`

### 7. Signing Attestation Copy (Fixed)
- **Issue:** Separation-of-duties copy was confusing, branched on rung alone without slot information
- **Fix:** Rewrote to derive wording from slot count, not rung; identity binding removed to engine vocabulary only

- **Files:** `src/ui-app/src/components/copilot/ApprovalCard.tsx`

### 8. Session-on-Mount (Implemented)
- **Feature:** `/copilot` page now opens a session and SSE stream on mount, instead of waiting for first run
- **Rationale:** Signing gate requires live stream for freshness verification; queue is unusable without it
- **Trade:** Creates one session per page load (distinguishable as `Review the approval queue` bootstrap objective)
- **Files:** `src/ui-app/src/components/copilot/CopilotContext.tsx`
