## Rulings Ratified

1. **Service split: `authority-service` is .NET** — Enforcement boundary and static typing on security-critical component justify the language boundary despite Python affinity elsewhere. Turk's single-service reasoning preserved in full and ratification alternative documented.

2. **Role provisioning into Phase 1** — `banker` and `supervisor` roles move to Phase 1; role hierarchy (`supervisor` ⊃ `banker`; `admin` implies NEITHER) with `effectiveRoles` computed at token issuance. Bootstrap via Terraform seed identity → idempotent startup seed. SoD enforced server-side with 8-step algorithm in §5.8.4. Non-breaking migration with optional `effectiveRoles` field.

3. **Two-browser demo accepted** — Intentional constraint; L2 beat uses two authenticated sessions (banker + supervisor) to demonstrate separation of duties as a visible handoff. No work to collapse into single session. Seed data must contain two distinct identities.

4. **Trajectory eval → epic #333** — Harness must emit structured, replayable traces from day one. Linus's `CopilotEventEnvelope` (`{id, seq, runId, kind, ts, payload}` over 20 event kinds) ratified as single trace schema of record. Eval-driven additions: durable persistence to `copilot-traces` (PK `/runId`), `traceId`/`spanId` on tool frames, model/deployment/token counts on model-call frames, `parentRunId` on subagent frames, redaction at emit time, `policyVersion` + resolved rung on `approval.required`. Key insight: eval question is not *"was the recommendation good?"* but **"did the authority ladder resolve correctly?"** — unanswerable without rung and policy version in trace.

5. **PolicyVersion binding — asymmetric void-on-escalation-only** — `policyVersion` bound into payload hash. At execution time, re-evaluate under CURRENT policy: higher required rung ⇒ signature void, re-propose; unchanged or lower ⇒ honour it. Never auto-downgrade, never auto-honour under-signed action. Same monotonic rule as escalators (invariant I-4), applied over time instead of context. Closes Q1; unblocks Turk's Phase 1 signature path.
