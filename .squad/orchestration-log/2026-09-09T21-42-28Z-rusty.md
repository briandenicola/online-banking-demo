## Summary

Fixed HTTP 400 rejection at approval 11 where `config/demo-dataset.json` approval `l2-score-override-pending` carried `"newScore": 0.25` as a JSON float. `Canonicalizer.WriteNumber` rejects floats outright on non-money fields.

## Notes

- The real lesson: the literal JSON is not what gets POSTed. `resolve_placeholders()` substitutes `{"@threshold": n, "@delta": d}` using jq arithmetic, and it is the *result* that is canonicalized. Eight approval `payload.amount` fields are exactly this shape; they survive today only because thresholds and deltas happen to be integral. A money threshold published as `1000.50` would break all eight at once.
- Guard does **not** change `seed_approvals` behavior — it only asserts what is sent. Asymmetry with probe path `money_from_threshold` flagged as follow-up for Danny.
