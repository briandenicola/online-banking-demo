## Work Delivered

### 1. SSE Response Header Stall (Fixed)
- **Issue:** `stream_session` held response headers for 15s on cold starts (`await runs.await_next_run` before `StreamingResponse`)
- **Fix:** Removed pre-flight await; reordered `_events()` loop to yield heartbeat before waiting
- **Verification:** 414 tests passed; new test `test_stream_flushes_its_first_frame_without_waiting_a_heartbeat` reproduces the defect on unfixed code and passes on fixed code
- **Files:** `src/banker-copilot-service/app/routes/sessions.py`, `tests/test_api.py`
- **Artifact:** Rusty's diagnosis confirmed at ASGI boundary; first byte now emits in <2s instead of 15.5s

### 2. Reason-Template Rendering (Fixed)
- **Issue:** Authority policy reason templates rendered unresolved `{placeholder}` text on cards
- **Fix:** Templates now resolve `{actual}` from predicate and `{threshold}` from policy; unresolved placeholders omit the sentence; empty results use fallback "Additional human review is required by the authority policy."
- **Scope:** No payload-hash fields changed; `agentAssessment` remains display-only
- **Files:** `src/authority-service/Policy/PolicyEvaluator.cs`

### 3. Counter-Proposal Support (Implemented)
- **Feature:** `context.supersedes=true` now flows to evaluator; new global escalator `superseding-proposal` fires at L2 only
- **Churn Guard:** Counts recent superseding proposals per requester; applies `raiseBy: 1` when count exceeds `POLICY_SUPERSEDE_CHURN_LIMIT` within `POLICY_SUPERSEDE_CHURN_WINDOW_SECONDS`
- **Spec:** Card backend fields (`evidence.label`, `evidence.summary`, `subject`) are display-only, computed at response time
- **Files:** `src/authority-service/Policy/EvaluationContext.cs`, `src/authority-service/Services/ApprovalService.cs`, `src/authority-service/Contracts/Contracts.cs`, `config/authority-policy.yaml`

### 4. Seeded Approval Assessments (Fixed)
- **Issue:** Demo seeded approvals did not carry assessment metadata
- **Fix:** `scripts/demo/demo.sh` now attaches `mode: seeded-demo` and `failureReason: seeded_direct_authority_proposal` to direct approvals
- **Testing:** 10/10 demo-dataset groups validated

### 5. Verification Corpus Dynamic Resolution (Implemented)
- **Issue:** `tests/verification/e2e_cases.py` hard-coded account UUIDs and balances; corpus was orphaned by reseeds
- **Fix:** New `seed_subjects.py` module resolves subjects at runtime from `config/demo-dataset.json`; all 32 cases re-authored against live ledgers
- **Semantics:** "A predicate used to select a subject must survive whatever regenerates the subject"
- **Fallback:** `supervisor_cases.py` uses synthetic identifiers; never resolves dynamically (component mode, no dataset access)
- **Files:** `tests/verification/seed_subjects.py` (new), `tests/verification/e2e_cases.py` (rewritten), `tests/verification/e2e_supervisor_probe.py`, `tests/verification/README.md`
