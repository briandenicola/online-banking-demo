## Root Cause

**`datasets.upload_file()` is NOT a direct blob write.** It's a server-side Foundry operation:
1. Client sends file bytes to Foundry API
2. API returns `file_id` (HTTP 200) — **misleading success**
3. Foundry backend attempts to write blob to PE-only storage
4. Backend has no network access to private endpoint (no PE-aware DNS, no VNET routing)
5. Blob write fails silently; eval run created but stuck forever
