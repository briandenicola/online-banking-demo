## Work Summary

**Issue:** `curl localhost:3000` returned "Connection reset by peer" — banking-ui-app container not serving HTTP requests.

**Root Cause:** Stale ui-app Docker image (4-week-old Alpine nginx:1.29 listening on port 80) reused by `docker compose up -d` without `--build` flag. Current Dockerfile (MCR-based Azure Linux nginx:1.28) listens on port 8080, mapped to host:3000 in docker-compose.yml, causing port mismatch.

**Secondary Issues:** 
- React build failed due to missing CSS module type declarations (`TS2882`)
- Azure Linux nginx lacks `/var/cache/nginx` and requires different logging configuration

**Fixes Applied:**
1. Added `src/ui-app/src/custom.d.ts` with CSS module type declarations
2. Updated `src/ui-app/Dockerfile` — removed chown of non-existent directories
3. Updated `src/ui-app/nginx.conf` — set `error_log stderr; access_log off;`
4. Updated `tasks/Taskfile.local.yml` — added `--build` flag to `local:run` task

**Verification:**
- `curl http://localhost:3000` → HTTP 200
- Response contains `<title>Online Banking Demo</title>`
- Container running and responsive

## Files Produced
- `src/ui-app/src/custom.d.ts` — CSS module type declarations

- `src/ui-app/nginx.conf` — Azure Linux-compatible logging
- `tasks/Taskfile.local.yml` — `--build` flag added to run task

## Learnings
- Stale cached images silently break stacks even when Dockerfiles are correct
- Azure Linux nginx has no `/var/cache/nginx`; use `stderr` logging when running as USER nginx
- Always rebuild after base image migrations; add `--build` to dev run commands
