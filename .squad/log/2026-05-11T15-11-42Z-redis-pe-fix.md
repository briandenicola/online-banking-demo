## Key Learning

DNS zone name is product-specific across Azure Redis variants. Azure Managed Redis (`azurerm_managed_redis`) requires `privatelink.redis.azure.net`, distinct from enterprise (`privatelink.redisenterprise.cache.azure.net`) and standard cache (`privatelink.redis.cache.windows.net`).
