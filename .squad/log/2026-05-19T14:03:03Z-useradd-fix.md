## Problem

5 Python Dockerfiles failed to build after MCR base-image migration:
- `src/chatbot-service/Dockerfile`
- `src/budget-service/Dockerfile`
- `src/ai-service/Dockerfile`
- `src/account-opening-service/Dockerfile`
- `src/ai-service/Dockerfile.eval-debug`

Error: `/bin/sh: line 1: useradd: command not found`

## Root Cause

MCR's `azurelinux/base/python:3.12` image does NOT include shadow-utils. The `useradd` command is unavailable.

## Solution

Replaced `RUN useradd ... + USER appuser` with numeric UIDs:
- `USER 1001` for standard services
- `USER 1000` for eval-debug (matches k8s `runAsUser: 1000`)

## Learnings

Azure Linux base images prioritize minimalism — they exclude package managers and user-management tools. **Numeric UIDs are the recommended approach** for container images. They're:
- Simpler (no dependencies)
- More portable (works on all base images)
- Kubernetes-safe (handles numeric UIDs without issues)
- More secure (fewer binaries = smaller attack surface)
